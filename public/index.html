Encryption & Security Specs

                
    
                  
  • Stream keys are encrypted with AES-256-GCM.
    • 
                  
  • Keys are decrypted in-memory only during FFmpeg execution.
    • 
                  
  • No stream keys are ever printed in browser responses or server logs.
    • 
                  
  • SSRF protection blocks all RFC 1918 private IPs and AWS/GCP metadata ranges.
